# SHRED

Track • Transform • Triumph

SHRED is an AI-powered fitness platform that helps users track nutrition, workouts, health metrics, and progress while providing intelligent coaching.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Recharts
- Supabase (Upcoming)
- OpenAI API (Upcoming)

## Run Project

```bash
npm install
npm run dev
```
